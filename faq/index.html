    常见问题¶

    旧版为什么不能直接更新到 1.0.0？¶

    1.0.0 更换了界面框架与浏览器内核。此次需要从 GitHub Release下载完整发行包重新安装，不能仅覆盖主程序。

    是否需要安装 WebView2 或 .NET？¶

    不需要。1.0.0 发行包包含 Qt 6 与 CEF 运行文件，旧版的组件要求不再适用。

    为什么下载体积比旧版大？¶

    新版随包提供完整浏览器内核与运行库，不再依赖系统 WebView2。

    为什么需要重新登录？¶

    旧版与新版使用不同内核。配置和书签迁移不代表浏览器 Cookies 可直接迁移。

    页面空白或加载失败怎么办？¶

    先检查网络与代理，再检查GPU 与环境报告。停用近期新增的扩展或脚本有助于缩小范围。不要先删除全部浏览器数据。

    双视图能登录两个独立账户吗？¶

    同一配置中的双视图共用登录资料。独立登录应使用不同账户配置。

    缓存是否包含所有游戏数据？¶

    不是。静态资源缓存不替代动态接口，也不支持离线游戏。清除 Cookies 与清除资源缓存的影响不同。

    所有 Chrome 扩展都能使用吗？¶

    不能保证。兼容性取决于 CEF 的能力、扩展 API 和扩展版本。
