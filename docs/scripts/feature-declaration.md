# 用户脚本说明

本栏目保留第三方脚本示例、作者与来源信息。示例不表示已在 Grancypher 1.0.0 内测版验证，也不保证后续游戏版本兼容。

## 使用前确认

- 阅读脚本内容和匹配域名，仅添加可信来源。
- 核对所需 API；内置加载器不提供完整 Tampermonkey 环境。
- 页面结构、浏览器内核或游戏更新后，脚本可能失效。
- 不需要时停用脚本，出现问题时先停用再排查。

脚本版权归原作者所有。如有署名或版权问题，请通过 [Issues](https://github.com/rawlkian/grancypher-release/issues)联系。

Grancypher 仅提供脚本加载接口。使用脚本前，请确认相关服务规则及账户风险。
