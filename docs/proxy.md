# 代理设置

入口：**设置 → 网络 → 代理**。

| 模式 | 说明 |
| --- | --- |
| 跟随系统 | 使用系统代理设置 |
| 直连 | 不使用代理 |
| 手动 | 填写代理服务提供的地址与端口 |
| PAC | 填写代理自动配置脚本地址 |

1. 确认代理客户端已经运行。
2. 按实际服务选择模式并填写地址。
3. 保存设置，按提示重启 Grancypher。
4. 重新加载主页，确认游戏及静态资源均能访问。

示例端口仅供参考，请使用代理客户端实际监听的端口。程序不会因填写代理地址而启动外部代理服务。

环境报告中的 DNS/TCP 检测始终直连，HTTPS 检测使用系统代理，与游戏的 CEF 代理设置独立。诊断成功不能单独证明游戏代理链路正常。
