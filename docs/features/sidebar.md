# 侧栏与图标管理

入口：**设置 → 外观 → 侧栏**；图标管理位于侧栏“更多”菜单。

## 布局

侧栏包含书签、工具、导航区域，可调整左右位置、宽度和区域顺序。拖动区块或使用界面提供的快捷操作改变顺序。

两条分区边界用于分配可用空间。空间不足时，部分工具图标进入“更多”菜单。锁定布局后不能拖动分区或调整相关图标顺序。

## 图标管理

1. 打开“更多 → 图标管理”。
2. 选择需要显示的导航、工具和扩展图标。
3. 按需调整顺序，点击“保存”。

取消或关闭窗口会放弃本次未保存的修改。隐藏项不会作为溢出项显示在“更多”中。

扩展可通过菜单固定到侧边工具区或取消固定。账户配置与扩展管理均提供独立入口。
