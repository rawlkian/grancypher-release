# 太郎与用户脚本

## 太郎窗口

先通过扩展管理加载本地太郎扩展，再使用程序中的太郎入口打开面板。

入口：**设置 → 游戏 → 太郎 Tarou**。

- **默认打开方式**：侧边栏或独立弹出窗口；修改后下次打开太郎时生效。
- **太郎弹窗吸附**：不吸附、主窗口左侧或主窗口右侧。
- **窗口记忆**：弹出窗口关闭后，重新打开会恢复上次的尺寸与位置。

如果太郎弹窗和书签悬浮栏都开启吸附，且位于同一侧，排列顺序为“主窗口 → 书签悬浮栏 → 太郎”。书签栏展开、收起时，太郎贴着它的实际外边缘；分处两侧时，各自贴着主窗口。其他扩展和网页弹窗不参与此排列。

拖动主窗口时，吸附面板同步跟随。屏幕空间不足时是否自动换边，由相应的自动换边设置决定。

## 用户脚本

通过用户脚本管理入口添加、启用或停用脚本。脚本按匹配规则在对应页面执行；修改后按界面提示重新加载页面。

内置加载器不等同于完整 Tampermonkey 环境。依赖 `GM_*`、远程依赖、页面私有对象或特定执行时机的脚本，需要分别验证兼容性。

## 使用与排查

1. 核对脚本来源、匹配域名和作用。
2. 每次启用一个脚本并检查页面行为。
3. 出现异常时先停用新增脚本，再重新加载。

本手册保留的[脚本示例](../scripts/feature-declaration.md)不表示已在 1.0.0 内测版逐项验证。第三方脚本的作者和来源保留在各示例页。
