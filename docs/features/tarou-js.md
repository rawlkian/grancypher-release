Grancypher 添加了对太郎插件及用户脚本（油猴脚本）的支持。

## 太郎

<img src="../img/tarou.png">

首先感谢太郎作者的更新与付出，<a href="https://waaatanuki.github.io/tarou-docs/begin/about">下载地址</a>。

目前 Grancypher 是针对太郎最新版本（截至撰写时点为 3.7.1）进行适配的，由于很多 Chrome 原生支持的插件入口和接口 WebView2 默认不具备，很多 Bug 与功能是在用户测试发现后再补上的，因此您如果在使用太郎过程中发现任何与 Chrome 环境下使用的差别或异常，烦请在<a href="https://bbs.nga.cn/read.php?tid=47650026">论坛原帖</a>提交问题，或通过其它途径联系我。

加载太郎只需要在设置窗口中选择太郎插件的所在文件夹，勾选启用即可。

**需要注意的是，如果 Grancypher 版本更新涉及到太郎的 Bug 修复，往往需要在设置中移除太郎并重新加载，否则修复无法生效。**

加载成功后，侧边栏会显示太郎图标，点击后会打开太郎窗口，Grancypher 会记忆太郎窗口大小。右击太郎图标可以选择是否吸附与吸附位置。

## 用户脚本

Grancypher 对油猴脚本的支持也是按需声明与添加的，目前测试下来几个比较常用的 GBF 脚本都可以正常使用，如果发现加载脚本之后网页卡加载或发生奇怪的问题，麻烦先禁用再试一试，有需要的话也可以提交问题。后续如果完成了对自定义插件的完整支持，会考虑将用户脚本功能取消，由油猴插件进行托管。
