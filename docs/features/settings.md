# 设置

## 分类

| 分类 | 主要内容 |
| --- | --- |
| 常规 | 界面语言、启动项、主页、欢迎引导 |
| 游戏 | 画面、交互、音频和兼容选项 |
| 外观 | 主题、强调色、材质、窗口与侧栏布局 |
| 网络 | 代理与浏览器身份 |
| 性能 | 低占用模式、GPU、资源缓存与预取 |
| 快捷键 | 功能绑定和冲突检查 |
| 书签 | 书签栏与悬浮窗的显示方式 |
| 数据 | 数据目录、缓存管理、清除、备份与还原 |
| 诊断 | 日志、环境报告与数据检查 |

账户配置使用侧栏的独立“用户配置管理”入口，不在普通设置分类中。

## 保存与重启

“应用”保存修改，“确定”保存并关闭，“取消”放弃未应用的修改。网络、GPU、缓存目录等项目按界面提示重启后生效。

## Skybound 外观

支持浅色、深色与系统颜色模式，提供强调色预设和自定义颜色。Skybound 使用蓝绿色、柔和浅色背景和细边框。

Mica、Mica Alt、Acrylic 等材质效果取决于系统版本、透明效果与硬件环境。窗口透明度会影响整个窗口及游戏画面；低于完全不透明时，系统材质可能回退。

## 低占用模式

入口：**设置 → 性能**。启用后使用不透明 Skybound 表面，减少阴影与部分界面动画。已保存的材质和透明度偏好不会被覆盖。

低占用模式不等于关闭游戏 GPU 加速。两项设置分别控制外壳效果与网页渲染。
