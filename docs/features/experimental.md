# 实验性设置

入口：**设置 → 实验性功能**。浏览器身份、图形后端和扩展静默调试均按用户配置保存，**应用或保存后重启生效**。Chrome 插件的即时管理另见[Chrome 插件支持](chrome-extensions.md)。

## 浏览器身份（UA）

0.4.5 起，提供内置身份选项，统一主窗、双窗、登录弹窗及相关请求：

| 选项 | 使用说明 |
| --- | --- |
| 默认（推荐） | 保持 WebView2 默认身份 |
| Android Chrome（移动端） | 需要移动端页面时优先试用 |
| iOS Safari（兼容性测试） | 仅改变身份信息，不能把 WebView2 变成 Safari |

1. 选择需要的身份。
2. 使用内置 UA 时关闭另装的 UA 切换扩展，避免重复修改。
3. 保存并重启，重新检查游戏和登录页面。

浏览器内核仍是 WebView2，不保证完整模拟手机浏览器或解决所有登录兼容问题。新版已修正登录弹窗沿用默认身份、移动端双窗宽度不重新适配的问题。

## 图形后端（ANGLE）

0.4.5 起，提供“自动（推荐）”“Direct3D 11”“OpenGL（兼容性测试）”，用于按需排查动画卡顿。

| 选项 | 说明 |
| --- | --- |
| 自动 | 默认值，让 Runtime 选择路径 |
| Direct3D 11 | 显式请求 D3D11 路径 |
| OpenGL | 兼容性试用；部分 Runtime 可能不支持并退回软件渲染 |

切换后保存并重启，再观察相同场景。**出现更慢或显示异常时，改回“自动”并再次重启。** 该选择不指定核显或独显，Chrome 中的图形 flags 也不会自动传给 Grancypher。

图形后端不能保证提升性能；卡顿还可能来自网页处理、插件或网络等待，不宜把开启 OpenGL 当成通用修复。

## 扩展静默调试

0.4.1 起，扩展静默调试默认开启。它隐藏其他插件通过调试器接口附加网页时的提示，并允许附加扩展后台页面；插件仍需相应权限，API 支持取决于 Runtime。

此选项独立于 Chrome 插件总开关，修改后需重启。关闭后其他插件恢复各自正常调试行为；**太郎始终通过宿主静默接收战斗数据，不受该选项影响**。

## 生效时机对照

| 操作 | 生效时机 |
| --- | --- |
| 浏览器身份、图形后端、扩展静默调试 | 保存后重启 |
| Chrome 插件总开关及插件管理 | 即时保存与处理，网页脚本影响需刷新 |
| 常规中的游戏窗口静音 | 应用后立即生效，不影响太郎通知 |

一次只更改需要检查的项目，有问题时记录配置、版本和具体症状，再查看[常见问题](../faq.md)。
