# 性能与兼容设置

新版将相关选项分别放入游戏、网络和性能分类。以下项目不应同时无差别开启。

| 设置 | 入口 | 用途 |
| --- | --- | --- |
| 低占用模式 | 性能 | 减少界面材质、阴影和部分动画 |
| GPU 硬件加速 | 性能 | 控制网页与游戏渲染加速 |
| 图形后端与具体显卡 | 性能 | 排查驱动、独显或核显选择问题 |
| User-Agent | 网络 | 调整浏览器身份 |
| 进程名伪装 | 对应兼容设置 | 根据界面提示使用并重启 |

图形设置修改后重启，并通过[环境报告](../diagnostics.md)核对实际状态。关闭 GPU 可能降低渲染性能；低占用模式不要求关闭 GPU。

旧版 WebView2 专用兼容项不适用于 CEF。不要将旧版组件修复方法直接用于 1.0.0。
