# 书签管理

## 添加与编辑

通过收藏入口保存当前页面。在书签管理器中可修改名称、网址、所属文件夹及图标。新建书签需填写并保存有效网址；取消操作不会保留未保存的修改。

右键菜单可在新弹窗打开书签，或使用当前页面替换书签地址。删除文件夹时，其下的书签会一并删除。

## 图标

支持远程图片、本地文件、文字图标及默认图标。文字图标可选择颜色或跟随强调色，保存前可查看预览。书签菜单、文件夹及嵌套菜单也显示对应图标；图片加载完成或切换明暗主题、强调色时即时刷新。

## 显示方式

入口：**设置 → 书签**。可选择内嵌书签栏或悬浮窗，并调整显示与缩放方式。

悬浮窗提供三种显示方式：紧凑模式平时仅显示图标，鼠标移入后横向展开，菜单打开期间保持展开；完整模式始终显示图标与标题；仅图标模式保持窄栏，不悬停展开，也不显示侧边拉伸把手。

贴在主窗口左侧时向左展开，图标在右、文字靠右；贴在右侧时向右展开。靠近主窗口的边缘保持固定。悬浮栏跟随主窗口层级，不会把其他网页或扩展窗口推开。

可从书签管理器直接拖入顶部、底部书签栏、悬浮窗或侧栏；固定显示不会改变书签原来的所属文件夹。

书签可按设置允许拖放排序。靠近屏幕边缘时，浮动面板会受可用空间约束。侧栏聚合书签与书签栏使用同一份书签数据。

## 扩展同步

扩展通过原生书签接口读取数据。书签管理器提示需要重启时，应重启程序后再检查扩展内的书签。
