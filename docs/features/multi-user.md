# 账户配置

入口：侧栏账户图标 → **用户配置管理**。

## 数据隔离

每个配置独立保存设置和登录资料。多个配置可以共用游戏静态资源缓存，不能通过共用浏览器资料目录实现独立登录。

## 创建与启动

1. 新建配置，输入不重复的名称。
2. 确认后启动该配置，并在游戏中登录。
3. 按需设置默认启动配置。

新配置使用独立 Cookies，默认共享缓存，不复制当前登录资料。显式打开某个配置不会自动修改默认启动选择。

## 重命名与删除

管理器提供独立勾选框和批量删除。当前、运行中、默认启动及初始配置受删除保护。

删除将永久移除所选配置的资料与 Cookies，无法恢复；共享缓存保留。执行前请核对选择并备份。

## 更改目录

按界面提供的目录操作迁移配置。已有有效目录可接入；需要迁移时，应先关闭使用相关目录的窗口，不要直接移动正在使用的浏览器资料。
