# Chrome 扩展

入口：侧栏的扩展入口或“管理扩展程序”。

## 安装与管理

使用扩展管理界面添加扩展。加载本地解压目录时，应选择包含 `manifest.json` 的扩展根目录，并按提示启用开发者模式。

扩展依赖 Chromium 与 CEF 提供的能力。并非所有 Chrome 扩展和 API 都与桌面 Chrome 完全兼容。

## 工具区入口

已安装扩展可在扩展菜单中打开。支持固定到侧边工具区、取消固定、使用 popup 或侧栏界面；具体行为取决于扩展声明。

扩展图标及显示顺序可在[图标管理](sidebar.md)中调整。

## 故障排查

- 确认选择了正确目录，且 `manifest.json` 可读取。
- 修改启用状态后，按程序提示重新加载或重启。
- 若扩展需要不受支持的 API，请向扩展作者确认兼容性。
- 排查页面异常时，先停用最近新增的扩展，再重新加载页面。
