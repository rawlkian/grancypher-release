# 本地缓存

开启入口：**设置 → 性能**。统计、体检、清理与目录操作位于 **设置 → 数据**。

## 缓存类型

| 类型 | 内容 |
| --- | --- |
| 浏览器缓存 | CEF 管理的 HTTP、代码和 GPU 缓存 |
| 托管资源缓存 | 程序管理的游戏静态 JS、CSS、图片及音视频资源 |
| 内存热缓存 | 可选的小资源内存副本，减少重复磁盘读取 |

托管缓存不替代游戏服务，不提供离线游戏。登录、战斗和结算等动态接口不作为静态资源缓存。不同配置可以共享资源缓存，登录资料仍独立保存。

## 可选功能

资源预取、页面预热及内存热缓存可分别设置。后台资源下载会参考前台加载状态；启用预取可能增加静态资源流量。

GPU 加速、缓存目录等需重启的选项以界面提示为准。

## 检查与清理

1. 刷新统计，查看占用、命中率、版本与后台任务。
2. 资源异常时先检查网络，再运行缓存体检。
3. 按需清空托管缓存，或仅删除不需要的旧版本。

版本管理默认保留最新版本及最近 7 天使用过的版本。删除前会重新检查，期间重新写入或变化的文件可能被跳过。

## 更改缓存目录

选择本机普通文件夹，不使用磁盘根目录或网络目录。程序提供复制原缓存或从空缓存开始两种方式；重启后使用新目录。

## 清除范围

| 操作 | 影响 |
| --- | --- |
| 清除缓存 | 下次访问重新下载资源，通常保留登录状态 |
| 清除 Cookies | 可能需要重新登录 |
| 清除全部浏览器数据 | 同时影响缓存、Cookies 和站点存储 |

清理共享缓存会使使用同一目录的其他配置重新下载相应资源。执行前请确认按钮对应的范围。
