# 双视图与窗口置顶

## 双视图

点击双视图图标打开第二个页面，拖动分隔握柄调整两个视图的空间。右键双视图入口可交换视图或关闭其中一侧。

在“设置 → 外观”中可选择“新视图从左侧打开”，下一次开启双视图时把新视图放在现有视图左侧。开启双视图时窗口会按两栏所需宽度加宽，不会把当前画面直接对半压缩。

两个视图属于同一账户配置，共用登录资料。需要两个独立登录状态时，应分别启动[账户配置](multi-user.md)。

## 新窗口

“新窗口”打开当前配置的另一个窗口。网页请求的独立弹窗由程序单独承载，不强制占用游戏视图。

## 置顶

通过窗口置顶工具切换窗口是否保持在其他普通窗口之上。系统安全界面和全屏应用可能优先于普通置顶窗口。
