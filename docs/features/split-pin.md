## 分屏功能

<img src="/img/split.png">

以“窗口切分”图标显示于侧边栏上，点击后会立刻复制当前打开的页面到右侧新打开的平行窗口中。

1. 右键图标可选择交换窗口位置、关闭指定窗口。
2. 两个窗口均可以调整大小或自适应裁剪。
3. 快捷键和功能图标会对当前激活（鼠标所在）窗口生效

> **注意事项：**
>
> 打开分屏的逻辑是复制当前页面网址到新的窗口打开，因此这种情况下 GBF 中“后退当作刷新”使用的特性会失效，在副本中需要先返回任务列表重进才可以继续将“后退当作刷新”使用。

## 置顶功能

以“图钉”图标显示于侧边栏上，点击开启后主窗体将置顶，右键可选择是否将太郎弹窗一同置顶。
