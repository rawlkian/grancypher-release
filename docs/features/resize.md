# 自适应画面

程序会在切换游戏 Size 档位、点击侧栏“重新适配游戏画面”或拖动窗口松手后，按游戏画面尺寸调整窗口。1.0.5 起按游戏缩放比例选择紧凑、标准或宽屏三档宽度，登录与认证页使用最小可读宽度。

- 页面加载本身不再自动改变窗口大小；设置中原有的“自动裁切游戏画面”开关已移除。
- 自动裁切可能在后续版本下线。页面注入样式中的 `:has()` 会导致战斗动画掉帧，1.0.5 已改为类选择器；若掉帧仍然明显，会考虑退回 GranBlue POPUP 式初始化与缩放裁切。
- 页面自动裁剪可在 **设置 → 游戏** 中调整。
- 拖动窗口或重新适配不会主动重新加载游戏页面。
- 双视图通过中间握柄分配空间，各视图保留自己的网页缩放设置。

如果当前页面不是受支持的游戏画面，适配结果可能与游戏主页不同。先等待页面加载完成，再执行手动适配。
