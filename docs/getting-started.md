# 第一次使用

## 初始设置

首次启动时，向导依次提供初始说明、存储位置、常用功能和设置确认。

1. 选择界面语言，以及官服或 Steam 服主页；也可保留已有主页。
2. 指定用户配置与缓存目录。已有有效配置目录可直接使用，不会由向导覆盖。
3. 按需设置本地资源缓存与窗口显示选项。
4. 确认后完成设置。取消向导后，下次启动会继续提示。

需要重新设置时，打开 **设置 → 常规 → 欢迎引导**。

## 登录与账户

在游戏页面完成登录。多个独立账户应分别创建[账户配置](features/multi-user.md)。同一配置的双视图共用登录资料，不提供独立登录隔离。

旧版与新版使用不同浏览器内核。迁移后可能需要重新登录，不应假定旧版 Cookies 可以直接使用。

## 常用入口

| 入口 | 功能 |
| --- | --- |
| 侧栏账户图标 | 创建、启动和管理账户配置 |
| 双视图 | 同时显示两个页面；右键可交换或关闭 |
| 重新适配 | 按当前游戏画面调整窗口 |
| 更多 | 访问溢出工具、扩展和图标管理 |
| 设置 | 调整游戏、外观、网络、性能、快捷键、书签与数据 |

若主页无法加载，先检查[代理设置](proxy.md)，再运行[环境诊断](diagnostics.md)。
