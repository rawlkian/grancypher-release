# 运行环境诊断

入口：**设置 → 诊断**。

## 生成环境报告

点击“生成环境报告”，等待网络与 GPU 检查完成。程序会保存 TXT 和 JSON 报告，并显示文件位置。

报告包含系统、程序版本、运行路径、磁盘空间、图形状态、扩展和网络检查。报告不读取账户密码、Cookies、书签内容或代理凭据；文件路径可能包含本机用户名，提交前请自行检查。

| 状态 | 含义 |
| --- | --- |
| PASS | 检查通过 |
| INFO | 状态信息 |
| WARN | 需要确认或无法完整判断 |
| FAIL | 检查到未满足的条件 |

报告使用当前界面语言；JSON 字段名和技术标识保持固定。

## 图形状态

“GPU 硬件加速”开关不等于硬件加速已实际生效。请查看报告中的实际 GPU 渲染状态，必要时打开 `chrome://gpu`。

在“设置 → 性能”中可选择默认、Direct3D 11、OpenGL 后端及具体显卡。修改后重启。虚拟机和远程桌面环境可能仅支持软件渲染。

## 记录日志

按需开启运行日志，重现问题后再关闭。开启不会补记此前发生的事件。反馈时附上版本、复现步骤、相关日志及报告，不要上传完整登录资料目录。

## 数据检查

书签数据检查用于发现重复 ID、孤立节点及父子循环。缓存检查位于 **设置 → 数据**，详见[本地缓存](features/local-cache.md)。
