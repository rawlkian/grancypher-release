## 获取程序本体

1. 打开 <a href="https://fluffygrimoire.site/grancypher/"> 官方网站 </a>
2. 点击前往下载，打开网盘输入密码，找到对应的版本，点击下载即可。

> Portable 为绿色便携版本，Setup 为完整的安装包程序，按照自己的需求选择即可。

## 环境依赖

推荐系统版本：Windows 10以上，以 Windows 11 为最佳。

### WebView2 Runtime

 电脑上有Chromium内核的Microsoft Edge便会自带，无需额外安装。

<a href="https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/">下载地址</a>

### Visual C++ 运行库

 大多数情况下你玩别的游戏或者安装别的程序已经顺带安装了，无需额外安装。

<a href="https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist">下载地址</a>

### Windows App SDK Runtime

 Win 11一般自带，没有就搜索下载安装下最新版。

<a href="https://learn.microsoft.com/zh-cn/windows/apps/windows-app-sdk/downloads">下载地址</a>

### .NET 10 Runtime

 最重要的，没有安装的话会提醒你下载安装，跟着操作就行。

<a href="https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0">下载地址</a>
