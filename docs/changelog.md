## 0.4.4

Grancypher 基于 WebView2 构建，Chrome 扩展依赖的标签页、权限、后台通信、书签和音频等浏览器能力，需要与 Grancypher 自己的窗口及数据逐一连接。适配的难点是让同一个标准接口在弹出窗口、后台 worker 和 offscreen 文档中都保持一致的授权、回调和生命周期，并让插件取得真实的数据与声音。我们会继续围绕通用 Chrome 接口完善适配，使使用同类接口的插件能够复用这些能力。

- 新增标准书签读取接口：声明并获准 `bookmarks` 权限的扩展可以读取当前账户的 Grancypher 书签，支持文件夹层级、搜索和实时读取；Shortkeys 等插件可以选择本地书签。
- 补齐通用标签页音频捕获与静音接口，修复 Volume Master 等音量插件无法生效的问题，支持音量放大与零音量。
- 内置用户脚本新增 `GM.audio` / `GM_audio` 接口，支持网页静音、状态读取和变化监听，覆盖 HTML 媒体与 Web Audio 输出。
- 修复侧栏右键菜单和“更多”菜单被太郎等置顶窗口遮挡的问题，保留用户原有的窗口置顶设置。
- 修复同网址的两个网页被混淆的问题，分别识别标签页、插件入口和音频状态，支持独立静音及捕获授权。
- 完善音频捕获的授权与释放：停用、重载或跨站导航后撤销旧授权，停止音轨或停用插件后释放捕获。
- 提供两份 GBF 静音用户脚本示例，其中网页音频版修正了声音没有经过静音节点的问题。

下载：[Grancypher v0.4.4](https://github.com/rawlkian/grancypher-release/releases/tag/v0.4.4)。
