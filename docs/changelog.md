# 更新日志

完整版本与下载以 [Releases](https://github.com/rawlkian/grancypher-release/releases) 为准。

## 0.3.5
- 用户配置文件夹中程序配置与书签文件分开保存，不影响备份与还原。

更新到此版本可能会出现旧版本书签丢失的情况（旧版本书签一同保存在 settings.json 中，现单独保存为 bookmarks.json，可手动迁移或使用备份还原功能）。

## 0.3.4

- 外观设置新增“页面加载时自动裁剪游戏右侧内容区域”，默认开启。
- 关闭后仍隐藏 Mobage 条，仍可用侧栏重新适配。
- 切换游戏底部 Size 档位始终自动适配，不受该开关影响。
- 新设置兼容既有配置，补充四语界面文案。

详见[自适应画面裁剪](features/resize.md)。

## 0.3.3

- 修正首次进入游戏时 Ctrl + 滚轮缩放不生效、需要切换网页的问题。
- 保留主、副视图独立缩放记忆，重启后恢复。
- 简化缓存设置说明和统计面板，同步四语翻译。

## 0.3.1

- Ctrl + 滚轮网页缩放保存到用户配置，重启后恢复。
- 主、副视图分别记忆，不同配置互不影响。
- 缩放范围保持 50%–250%，异常配置值进行归一化处理。

## 0.3.0

- 默认开启 GBF 静态资源缓存，与 WebView2 原生缓存共同使用。
- 静态缓存取消固定总容量上限；低于 2 GiB 可用空间暂停新增写入，不自动清理正常历史版本。
- 新增缓存统计、体检、版本预览清理、媒体后台补齐与前台优先调度。
- 提供可选内存热缓存、游戏资源预拉取和常用页面预热，默认关闭；可暂停后台下载。
- 改善 Windows 窗口吸附，新增附属面板自动换边与未激活时保持材质开关。
- 改善游戏适配、登录弹窗导航保护、鼠标快捷键优先级与配置迁移流程。
- 新配置默认写入 AppData，保留明确选择的配置与 Cookies 目录，完善四语翻译。

详见[本地缓存](features/local-cache.md)、[多用户配置](features/multi-user.md)。

## 0.2.3

- 改善首次画面适配、右侧菜单裁剪、小尺寸及 Size 档位变化处理。
- 新配置与首次向导默认开启本地缓存，保留旧配置显式关闭的选择。
- 用户配置、Cookies 与目录迁移流程统一管理，支持选择有效已有配置。
- 默认数据根目录使用 `Grancypher`，不自动识别旧 `GranblueBrowser` 默认目录。
- 配置显示名称可独立修改，不改变目录或启动标识。
- 改善文件选择器、迁移进度、鼠标快捷键区域与登录诊断。

## 升级提醒

升级前关闭所有实例，分别备份设置与书签。发行包不含个人资料，且不捆绑运行组件。程序没有自动更新；跨旧数据目录升级时请核对实际配置位置。

安装步骤见[安装与环境配置](install.md)，疑难处理见[常见问题](faq.md)。
