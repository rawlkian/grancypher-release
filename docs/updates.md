# 程序更新与旧版迁移

## 1.x 程序内更新

打开“关于 Grancypher”，检查更新后按提示下载、安装并重启。程序会选择适合当前安装方式的安装包或便携包，并验证下载文件的 SHA-256 摘要。

当前正式版为 [1.0.5](https://github.com/rawlkian/grancypher-release/releases/tag/v1.0.5)。若程序内检查或下载遇到网络问题，可直接从发布页下载完整发行包。

手动更新前请退出程序及所有账户窗口。安装版运行新版安装程序；便携版完整解压运行文件，保留原有 `Data` 资料目录及 `portable.flag`。

## 0.x 旧版迁移

!!! warning "旧版需要完整下载安装"
    0.x 使用 WebView2，1.x 使用 Chromium（CEF）。两代运行文件和浏览器资料不兼容，不要通过旧版的自动更新直接安装新版，也不要仅替换主程序。

1. 在旧版中备份配置、书签等资料，并保留原数据目录。
2. 完全退出旧版及其他账户窗口。
3. 下载 1.0.5 的完整安装包或便携包。
4. 安装或解压到新的空目录，不要混合两代运行文件。
5. 完成初始设置，按需使用已有配置或导入备份，核对书签与设置；迁移后可能需要重新登录。
6. 确认新版正常工作后再处理旧版文件。

不要手工合并两种内核的 Cookies、缓存或浏览器内部资料。
