# 程序更新与旧版迁移

!!! warning "1.0.0 内测版必须完整下载安装"
    此次无法在旧版 Grancypher 内自动更新。请前往 [GitHub Release](https://github.com/rawlkian/grancypher-release/releases/tag/v1.0.0) 下载完整安装包或便携包，并重新安装。

## 升级步骤

1. 在旧版中备份配置、书签等资料，并保留原数据目录。
2. 完全退出旧版及其他账户窗口。
3. 下载 1.0.0 内测版的完整发行包。
4. 安装版运行新的安装程序；便携版解压到新的空目录，不要覆盖式混合两代运行文件。
5. 完成初始设置，按需使用已有配置或导入备份，核对书签与设置。
6. 确认新版正常工作后再处理旧版文件。迁移后可能需要重新登录。

新版采用 Chromium（CEF）内核，旧版使用 WebView2。不要手工合并两种内核的 Cookies、缓存或浏览器内部资料。

## 版本标记

- **1.0.0 内测版**：GitHub 预发布版本，供测试使用。
- **旧版升级通知**：不包含自动更新附件，仅提供完整下载与迁移说明。

旧版需开启启动更新检查且能访问 GitHub，才会在后续检查时显示通知。关闭检查或已跳过通知的用户可直接访问 Release 页面。

## 后续更新

新版可在“关于”中检查更新。只有找到适用于当前架构和安装方式、且带有效校验信息的附件时，才提供下载与安装操作。没有适用附件时，使用发布页面查看说明并手动下载。
