    更新日志¶

    1.0.5 正式版 · 2026-11-10¶

    游戏画面适配¶

    • 重做游戏画面自适应：按游戏自身的缩放比例和紧凑、标准、宽屏三档宽度决定窗口尺寸，登录与认证页使用最小可读宽度。
    • “设置 → 游戏”移除“自动裁切游戏画面”开关。页面加载时不再自动改变窗口大小，只在切换 Size 档位、点击“重新适配”或拖动窗口松手后测量。
    • 页面注入样式去掉 :has() 选择器，改用类选择器配合宽度档位控制侧栏显示，降低战斗动画期间的样式重算开销。
    • 游戏页屏蔽 IdentityCredential，Mobage 登录改走弹窗流程，避免 FedCM 交接失败。
    • 拖动窗口期间暂停适配，松手后按宽度是否变化决定是否重测；适配防抖从 650ms 收紧到 150ms。

    双视图¶

    • “设置 → 外观”新增“新视图从左侧打开”。
    • 开启双视图时按两栏所需宽度加宽窗口，不再把当前画面直接对半压缩；恢复已保存的双视图时，只在游戏需要更多空间时加宽。
    • 修复关闭一侧后保留窗格未铺满窗口，以及主窗格提升后画面仍按半宽渲染的问题。

    太郎¶

    • 太郎弹窗支持 Ctrl + 滚轮缩放页面内容，重新打开后恢复为 100%。
    • 太郎作为侧边栏展开时记录窗口扩展量，关闭时只收回为它增加的宽度和位置。
    • 太郎弹窗最小宽度放宽到 160 DIP。

    书签与扩展¶

    • 书签菜单、文件夹图标按原比例居中绘制，不再被拉伸。
    • 修复扩展侧边栏关闭后宿主未收到通知、窗口与游戏区域不还原的问题。
    • 扩展弹层内容准备好之前不再提前显示。
    • 启动时清理已不存在的扩展目录，并同步从禁用列表移除。

    窗口与启动¶

    • 再次启动程序默认打开新的主窗口；带 --activate 启动时才把已有窗口调到前台。
    • 主窗口隐藏时关闭网页弹窗，不再退出整个应用。
    • 新配置默认隐藏地址栏，使用内嵌页面布局。

    关于自动裁切¶

    • 自动裁切（页面加载后自动把窗口收缩到游戏画面宽度）以后版本或许会下线。
    • 1.0.5 使用的 :has() 样式注入会导致动画掉帧。本次已移除 :has()，但如果在战斗中问题仍然明显，会考虑退回 GranBlue POPUP 式的初始化和缩放裁切。

    1.0.4 正式版 · 2026-11-09¶

    • “设置 → 游戏”新增太郎（Tarou）专属选项，可选择默认使用侧边栏或独立弹出窗口。
    • 太郎弹窗支持不吸附、吸附主窗口左侧或右侧，每次打开恢复上次的窗口尺寸与位置。
    • 太郎与书签悬浮栏同时吸附且在同一侧时，按“主窗口 → 书签栏 → 太郎”排列；分处两侧时各自贴着主窗口。书签栏展开、收起和主窗口拖动时同步调整太郎位置。
    • 修正太郎窗口尺寸被浏览器默认布局覆盖的问题，改善缩放、最小化恢复及侧边栏与弹窗之间的切换。
    • 恢复书签菜单、文件夹及嵌套菜单中的图标；远程图片加载完成、切换明暗主题或强调色时及时刷新。
    • 修正扩展加载较慢时入口未及时刷新，以及面板尚未创建完成就关闭时的处理。

    1.0.3 正式版 · 2026-11-08¶

    • 悬浮书签新增“仅图标”显示方式，并收紧窄栏宽度；图标始终显示，不再单独提供“显示图标”开关。
    • 左侧悬浮书签向左展开，文字靠右、图标在右；右侧向右展开。展开与收起使用平滑动画，贴着主窗口的边缘和图标列保持固定，拖动把手的圆点随可见面板居中。
    • 修正贴边吸附覆盖游戏画面的问题，改善拖动主窗口时悬浮书签栏的跟随。
    • 悬浮书签栏跟随主窗口层级，不再自动推开其他弹窗；应用无关设置时不再强制抬到设置窗口上方。
    • 网页弹窗统一使用细边框，并在标题栏增加独立置顶按钮，只影响当前弹窗。
    • 修正顶部、底部书签栏的悬停高亮范围，恢复从书签管理器拖入书签栏和侧栏。
    • 修正新建书签、文件夹时输入框首次聚焦的底部高亮线长度。
    • 补齐主题色、明暗模式和材质切换时的界面刷新，覆盖拖动块、列表卡片、菜单、欢迎向导及扩展管理等位置。
    • 精简缓存操作：移除版本管理和重复的清理按钮，保留一个“清除缓存”入口，同时清理游戏资源缓存与浏览器缓存，保留 Cookies 和登录状态。
    • 更新检查入口统一放在“关于 Grancypher”，移除更多菜单中的重复入口。

    1.0.0 内测版 · 2026-11-08¶

    本次为 Qt 6 与 Chromium（CEF）重写版。旧版无法通过程序内自动更新，请下载完整包重新安装。

    界面与窗口¶

    • 统一 Skybound 主题、弹窗、菜单和自定义强调色界面。
    • 提供首次启动引导，设置配置目录、缓存目录和游戏主页。
    • 完善窗口位置与尺寸记忆、双视图、侧栏分区及浮动书签交互。
    • 修正多窗口、附属面板和弹窗关闭相关问题。

    账户、书签与扩展¶

    • 恢复独立账户配置入口，提供批量选择与删除保护。
    • 改进书签新增、文件夹编辑、图标预览与保存行为。
    • 整理扩展菜单、侧栏固定入口与图标管理。

    性能与数据¶

    • 提供低占用界面模式、图形后端和具体显卡选择。
    • 完善静态资源缓存、版本管理、完整性检查与目录迁移。
    • 提供运行日志、网络检测及实际 GPU 状态报告。

    发行与语言¶

    • 提供完整 Windows x64 便携版与安装版，以及 SHA-256 校验文件。
    • 安装向导使用新 Skybound 插画和正式说明文案。
    • 更新关于介绍，补齐四语言文案、动态状态和辅助功能名称，修正语言切换及占位符问题。

    旧版发行记录保留于 GitHub Releases。
