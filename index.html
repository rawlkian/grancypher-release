    版本说明¶

    本手册适用于 Grancypher 1.0.5。新版使用 Qt 6 与 Chromium（CEF），发行包包含所需运行文件，无需另行安装 WebView2、.NET 或 Windows App SDK。

    程序支持简体中文、繁體中文、English 和日本語。界面语言立即切换；浏览器内部菜单语言在重启后生效。

    Grancypher 为非官方应用，与 Cygames 无隶属关系。问题请通过 GitHub Issues反馈。
